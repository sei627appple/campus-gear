【大学生向け】Macの便利なショートカットキー25選｜レポート作成が一気に速くなる

Mac公開日：2026年9月30日

Macを使っていて、「毎回メニューから操作していて時間がかかる」と感じたことはありませんか？ よく使う操作をショートカットキーで覚えておくと、レポート作成や調べものの時間がかなり短くなります。

この記事では、大学生が実際によく使う場面に絞って、覚えておきたいショートカットを紹介します。

まず覚えるならこの5つ
  • command + Space：Spotlight（アプリやファイルを検索して起動）
  • command + Tab：アプリの切り替え
  • command + shift + 4：範囲を選んでスクリーンショット
  • command + Z / command + shift + Z：取り消し／やり直し
  • command + F：ページ内・文書内の検索

キーの記号の読み方

Macのメニューには、ショートカットが記号で表示されています。最初にこれを覚えておくと、メニューを見るだけで新しいショートカットを覚えられます。

記号キー
⌘command
⇧shift
⌥option
⌃control
fn / 🌐fn（地球儀）キー

基本の編集ショートカット

ショートカットできること
command + C / V / Xコピー／貼り付け／切り取り
command + Aすべて選択
command + Z取り消し
command + shift + Zやり直し
command + S保存
command + option + shift + V書式なしで貼り付け（アプリによって異なる）

レポートでは「書式なし貼り付け」が便利

Webサイトから文章をコピーしてレポートに貼ると、フォントや文字の大きさまで一緒に付いてきてしまうことがあります。そんなときはcommand + option + shift + V（Pages・メモなど）や、Wordの「テキストのみ保持」で貼り付けると、書式がそろってきれいです。

※引用する場合は、出典を必ず書きましょう。

文字入力・カーソル移動

ショートカットできること
command + ← / →行の先頭／末尾へ移動
command + ↑ / ↓文書の先頭／末尾へ移動
option + ← / →単語単位で移動
shift + 上記の移動キー移動しながら範囲選択
option + delete単語単位で削除
control + Kカーソルから行末まで削除

日本語入力の変換にも使えるキー

  • control + K（変換中）：カタカナに変換
  • control + J（変換中）：ひらがなに戻す
  • control + ;（変換中）：半角英数に変換

英単語や学籍番号を打つときに、いちいち入力モードを切り替えなくて済みます。

アプリ・ウインドウの操作

ショートカットできること
command + SpaceSpotlightで検索・起動
command + Tabアプリ切り替え
command + `（バッククォート）同じアプリ内のウインドウ切り替え
command + Wウインドウ・タブを閉じる
command + Qアプリを終了
command + Hアプリを隠す
command + option + escアプリを強制終了

ウインドウを閉じるcommand + Wと、アプリごと終了するcommand + Qは間違えやすいので注意。保存していない書類がある場合は確認が出ますが、覚えておくと安心です。

ブラウザ（Safari・Chrome）で使えるもの

ショートカットできること
command + T新しいタブ
command + shift + T閉じたタブを復活
command + Lアドレスバーを選択
command + Fページ内検索
command + + / −拡大／縮小
command + 数字数字番目のタブへ移動

論文や資料を調べているとき、command + Fでキーワードを検索すると、長いページでも必要な部分がすぐ見つかります。

スクリーンショット

ショートカットできること
command + shift + 3画面全体を撮影
command + shift + 4範囲を選んで撮影
command + shift + 4 → spaceウインドウを選んで撮影
command + shift + 5撮影メニュー（画面収録もできる）
上記 + controlファイルにせずクリップボードにコピー

スクショの保存先を変える方法などは、Macのスクショ・PDF操作の記事で詳しく紹介しています。

Finder（ファイル操作）

ショートカットできること
spaceクイックルック（ファイルを開かずに中身を確認）
command + shift + N新規フォルダ
command + deleteゴミ箱に入れる
return名前の変更
command + D複製
command + shift + .（ピリオド）隠しファイルの表示／非表示

特にspace（クイックルック）は便利で、PDFや画像をいちいちアプリで開かなくても、中身をすぐに確認できます。

覚えるコツ

  • 一度に全部覚えない：まずは「まず覚えるならこの5つ」から
  • メニューに書いてある記号を見る：よく使う操作のショートカットが自然に覚えられる
  • 付箋に書いてPCの近くに貼る：1週間もすれば手が覚えます

まとめ

ショートカットは、1回あたりの短縮時間は数秒でも、毎日使えば大きな差になります。まずはSpotlight、アプリ切り替え、スクショ、ページ内検索の4つから使ってみてください。

※アプリやmacOSのバージョンによって、ショートカットが異なる場合があります。
