Macでレポートを書くときに覚えておくと楽なショートカット

Macのショートカットはたくさんありますが、全部を覚える必要はありません。よく使う操作だけでも手が覚えてしまえば、レポートを書く時間や調べものの時間はけっこう短くなります。

ここでは、大学の課題をやっているときに出番が多いものを場面ごとにまとめました。

とりあえずこれだけは

いきなり全部は覚えられないので、最初はこの4つだけで十分だと思います。

  • command + Space：Spotlight。アプリやファイルを名前で探して開ける
  • command + Tab：開いているアプリを切り替える
  • command + F：ページや文書の中を検索する
  • command + shift + 4：範囲を選んでスクリーンショット

特にSpotlightは、Launchpadやアプリケーションフォルダからアプリを探すよりずっと速いので、慣れるとこればかり使うようになります。

メニューの記号の読み方

Macのメニューには、ショートカットが記号で書かれています。⌘がcommand、⇧がshift、⌥がoption、⌃がcontrolです。これさえわかれば、よく使う操作のショートカットはメニューを見て自分で覚えられます。

文章を書いているとき

キーできること
command + Z取り消し
command + shift + Zやり直し
command + ← / →行の先頭・末尾へ移動
command + ↑ / ↓文書の先頭・末尾へ移動
option + ← / →単語ごとに移動
上の移動キー + shift移動しながら範囲選択
option + delete単語ごとに削除

カーソル移動とshiftを組み合わせると、マウスで文字をなぞらなくても範囲選択ができます。長い文章を書き直すときに便利です。

書式なしで貼り付ける

Webページの文章をコピーしてレポートに貼ると、フォントや文字の大きさまで一緒についてきて、そこだけ見た目が変わってしまうことがあります。

そういうときはcommand + option + shift + Vで、周りの書式に合わせて貼り付けられます（対応していないアプリもあります）。Wordの場合は、貼り付けたあとに出るアイコンから「テキストのみ保持」を選んでも同じことができます。

もちろん、ほかの人の文章を使うときは引用のルールを守って、出典を書いてください。

日本語入力で地味に便利なもの

変換中にcontrol + Kを押すとカタカナ、control + ;を押すと半角英字になります。英単語や学籍番号を入力するときに、いちいち入力モードを切り替えなくていいので楽です。

アプリやウインドウを扱うとき

キーできること
command + `同じアプリのウインドウを切り替える
command + Wウインドウやタブを閉じる
command + Qアプリを終了する
command + Hアプリを隠す
command + option + escアプリを強制終了する

WとQは隣にあるので、ウインドウを閉じるつもりでアプリごと終了してしまうことがあります。保存していない書類があれば確認が出ますが、少し気をつけてください。

ブラウザで調べものをしているとき

SafariでもChromeでも、だいたい同じキーが使えます。

  • command + T：新しいタブ
  • command + shift + T：間違えて閉じたタブを開き直す
  • command + L：アドレスバーに移動
  • command + 数字：その番号のタブに移動

論文や長い資料を読むときは、command + Fで探したい言葉を検索すると、必要なところにすぐ飛べます。

スクリーンショット

画面全体はcommand + shift + 3、範囲を選ぶならcommand + shift + 4です。4のあとにspaceを押すと、ウインドウ単位で撮れます。

どれもcontrolを一緒に押すと、ファイルを作らずにコピーだけされるので、そのままLINEや資料に貼り付けられます。保存先の変え方などは、スクショとPDFの操作についての記事に書きました。

Finderでファイルを扱うとき

ファイルを選んでspaceを押すと、アプリを開かずに中身をプレビューできます（クイックルック）。PDFや画像がどれだったか確認したいときに便利で、Finderの操作の中でも特に覚えておきたいものです。

ほかには、新しいフォルダを作るcommand + shift + N、名前を変えるreturn、ゴミ箱に入れるcommand + deleteあたりを覚えておくと、ファイルの整理が速くなります。

覚え方について

一覧を眺めても、なかなか覚えられないものです。よく使う操作をするときに、一度メニューを開いて横に書いてある記号を見る、というのを繰り返していると、自然に手が覚えていきます。

※アプリやmacOSのバージョンによっては、ショートカットが違う場合があります。
