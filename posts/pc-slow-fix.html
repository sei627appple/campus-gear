パソコンが重い・遅いときの対処法｜Mac・Windows別に今すぐできること

PCトラブル公開日：2026年9月30日

レポートの締め切り直前に限って、パソコンが重くなる……。そんなときに、お金をかけずに今すぐ試せる対処法をMac・Windows別にまとめました。上から順番に試してみてください。

チェックする順番
  1. 再起動する
  2. 重いアプリ・処理を探して終了する
  3. ブラウザのタブと拡張機能を減らす
  4. ストレージの空き容量を増やす
  5. 起動時に自動で立ち上がるアプリを減らす
  6. OS・アプリをアップデートする

1. まずは再起動

基本ですが、いちばん効果があることも多いのが再起動です。長期間スリープだけで使い続けていると、メモリに不要なデータがたまって動作が重くなることがあります。

  • Mac：アップルメニュー →「再起動」
  • Windows：スタート → 電源 →「再起動」（「シャットダウン」より再起動のほうが、しっかりリセットされます）

作業中のファイルは、再起動の前に必ず保存しておきましょう。

2. 重いアプリ・処理を探す

Mac：アクティビティモニタ

  1. command + SpaceでSpotlightを開き、「アクティビティモニタ」と入力して起動
  2. 「CPU」タブや「メモリ」タブで、上位に来ているアプリを確認
  3. 使っていないアプリなら、普通に終了する（反応しない場合は強制終了）

「メモリ」タブの下にある「メモリプレッシャー」が黄色や赤になっていたら、メモリが足りていないサインです。

Windows：タスクマネージャー

  1. Ctrl + Shift + Escでタスクマネージャーを開く
  2. 「プロセス」で、CPUやメモリの使用率が高いアプリを確認
  3. 不要なアプリを選んで「タスクを終了する」
注意

名前がよくわからないシステムのプロセスは終了しないようにしましょう。PCが不安定になることがあります。終了するのは、自分で起動したアプリだけにするのが安全です。

3. ブラウザのタブと拡張機能を減らす

実は、PCが重くなる原因でとても多いのがブラウザです。タブを数十個開いていると、それだけで大量のメモリを使います。

  • 使っていないタブは閉じる（あとで読みたいページはブックマークやリーディングリストへ）
  • 使っていない拡張機能は削除・無効にする
  • ChromeやEdgeには、使っていないタブのメモリを自動で解放する「省メモリ」系の機能があるので、オンにしておく

4. ストレージの空き容量を増やす

ストレージ（SSD）の空き容量が少なくなると、動作が遅くなったり、アップデートができなくなったりします。少なくとも全体の1〜2割は空けておくのがおすすめです。

  • Mac：システム設定 →「一般」→「ストレージ」で、何が容量を使っているか確認できる
  • Windows：設定 →「システム」→「ストレージ」。「ストレージセンサー」をオンにすると、一時ファイルなどを自動で削除してくれる

容量を圧迫しやすいのは、動画、写真、ダウンロードフォルダ、使っていないアプリです。大きなファイルはクラウドや外付けSSDに移しましょう。クラウドの選び方はクラウドストレージの使い分けの記事で紹介しています。

5. 起動時に自動で立ち上がるアプリを減らす

PCの電源を入れたときに、自動で起動するアプリが多いと、起動が遅くなり、裏で動き続けて重くなります。

  • Mac：システム設定 →「一般」→「ログイン項目」で、不要なアプリを削除
  • Windows：タスクマネージャー →「スタートアップ アプリ」で、不要なアプリを「無効化」

6. OSとアプリをアップデートする

アップデートで不具合が直り、動作が軽くなることがあります。セキュリティのためにも、OSやブラウザは最新の状態にしておきましょう。

  • Mac：システム設定 →「一般」→「ソフトウェアアップデート」
  • Windows：設定 →「Windows Update」

ただし、大学指定のソフトがある場合、大きなOSアップデートの直後は対応していないこともあります。レポートや試験の直前は避けて、余裕のあるときにアップデートするのが安心です。

それでも重いときは

  • ウイルス対策ソフトでスキャンする（Windowsなら標準の「Windows セキュリティ」でOK）
  • ノートPCの底面や通気口がふさがっていないか確認する。熱がこもると性能が落ちる
  • メモリ8GB以下のPCで、やりたい作業が重すぎる場合は、PCの性能自体が足りていない可能性も

買い替えを考えている人は、大学生のノートPCの選び方を参考にしてください。

まとめ

PCが重いときは、再起動 → 重いアプリの確認 → ブラウザのタブ → 空き容量 → 起動時アプリ → アップデートの順に試してみましょう。ほとんどの場合、どれかで改善します。
