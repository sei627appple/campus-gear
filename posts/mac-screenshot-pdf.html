MacのプレビューでPDFの結合や圧縮はだいたいできる

大学の課題では、「PDFで提出」「複数のファイルを1つにまとめて提出」「ファイルサイズは〇MBまで」という指示がよくあります。こういうとき、Macなら追加でアプリを入れなくても、最初から入っている「プレビュー」でほとんど対応できます。

ついでに、スクリーンショットのちょっとした設定についても書いておきます。

複数のPDFを1つにまとめる

  1. まとめたいPDFのうち、1つ目をプレビューで開く
  2. メニューの「表示」から「サムネール」を選んで、左側にページの一覧を出す
  3. 2つ目のPDFファイルを、Finderからそのサムネールの中にドラッグする
  4. 「ファイル」→「PDFとして書き出す」で保存する

サムネールの並び順がそのままページの順番になります。ページはドラッグで並べ替えられるので、表紙を先頭に持ってくる、といったこともここでできます。

いらないページを消す、向きを直す

サムネールでページを選んでdeleteを押すと、そのページを削除できます。スキャンしたら横向きになっていた、というページは、選んでcommand + R（右に回転）かcommand + L（左に回転）で直せます。

写真やスクショをPDFにする

手書きのノートを写真に撮って提出するときなどに使える方法です。画像を全部選んでプレビューで開き、「ファイル」→「プリント」を選びます。左下の「PDF」から「PDFとして保存」を選ぶと、1つのPDFにまとまります。

PDFに直接書き込む

ツールバーにあるペンのアイコンを押すと、文字を入れたり、線を引いたり、ハイライトを付けたりできます。配られたPDFのプリントに答えを書き込んで提出するときや、資料にメモを残したいときに便利です。

ファイルサイズを小さくする

提出フォームに容量の上限があって、PDFが大きすぎて出せない、ということがたまにあります。

  1. PDFをプレビューで開く
  2. 「ファイル」→「書き出す」を選ぶ
  3. 「Quartzフィルタ」で「Reduce File Size」を選んで保存する

画像が多いPDFほど小さくなりますが、そのぶん画質もかなり落ちます。保存したら一度開いて、文字がちゃんと読めるか確認してください。元のファイルは上書きせずに、別の名前で保存しておくのがおすすめです。

WordやPagesの書類をPDFにする

Wordなら「ファイル」→「名前を付けて保存」でファイル形式をPDFに、Pagesなら「ファイル」→「書き出す」→「PDF」です。どのアプリでも、「プリント」の画面の左下から「PDFとして保存」を選べばPDFにできます。

PDFにするとレイアウトが少しずれることがあるので、提出する前に開いて確認しておくと安心です。

スクリーンショットの保存先を変える

スクショは最初の設定だとデスクトップに保存されるので、しばらく使っているとデスクトップがスクショだらけになります。

command + shift + 5を押すと画面の下にメニューが出るので、「オプション」から保存先を選べます。「スクショ」のようなフォルダを作って、そこに保存するようにしておくと後で探しやすいです。

撮るときにcontrolを一緒に押すと、ファイルを作らずにコピーだけされます。資料やチャットにすぐ貼りたいときはこちらのほうが楽です。

画面を動画で録る

同じcommand + shift + 5のメニューから、画面の録画もできます。発表の練習を録って見返したり、操作のやり方を人に説明したりするときに使えます。

オンライン授業の映像や配布資料を録画・撮影して人に渡すのは、著作権や大学のルールに反することがあります。録るとしても、自分の勉強用にとどめておいてください。

ほかのショートカットについては、Macでレポートを書くときに覚えておくと楽なショートカットにまとめています。

※macOSのバージョンによって、メニューの名前や場所が少し違うことがあります。
