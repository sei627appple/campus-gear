Macのスクショ・PDF操作まとめ｜保存先の変更からPDFの結合・圧縮まで無料でできる

Mac公開日：2026年9月30日

大学では、「資料をPDFで提出」「複数のファイルを1つのPDFにまとめて提出」「ファイルサイズは○MB以内」といった指示がよくあります。

実はMacなら、追加のアプリを入れなくても、標準の「プレビュー」だけでほとんどのPDF操作ができます。スクリーンショットの便利な使い方と合わせて紹介します。

スクリーンショットの基本

ショートカット撮れる範囲
command + shift + 3画面全体
command + shift + 4ドラッグで選んだ範囲
command + shift + 4 → space選んだウインドウ（影付き）
command + shift + 5撮影メニュー（画面収録・タイマー・保存先の設定）

どのショートカットも、controlを一緒に押すとファイルを作らずにクリップボードにコピーされます。LINEやSlack、レポートにそのまま貼りたいときに便利です。

スクショの保存先を変える

初期設定ではデスクトップに保存されるので、すぐにデスクトップがスクショだらけになります。

  1. command + shift + 5を押す
  2. 下に出るバーの「オプション」をクリック
  3. 「保存先」から、書類フォルダや自分で作ったフォルダを選ぶ

「スクショ」フォルダを作って、そこに保存するようにしておくと整理が楽です。

画面収録（動画）もできる

command + shift + 5のメニューから、画面の動画も撮れます。オンライン発表の練習や、操作手順を人に説明するときに使えます。マイクの音声を入れるかどうかは「オプション」で選べます。

注意

オンライン授業の映像や資料を録画・撮影して共有するのは、著作権や大学のルールに反する場合があります。自分の学習用にとどめ、共有する前にルールを確認しましょう。

「プレビュー」でできるPDF操作

PDFをダブルクリックすると開く「プレビュー」は、実はかなり高機能です。

1. 複数のPDFを1つにまとめる

  1. 1つ目のPDFをプレビューで開く
  2. メニューの「表示」→「サムネール」を選び、左側にページ一覧を出す
  3. まとめたい2つ目のPDFファイルを、Finderからサムネールの中にドラッグ＆ドロップ
  4. 「ファイル」→「PDFとして書き出す」で保存

サムネールの並び順が、そのままページの順番になります。ドラッグで並べ替えもできます。

2. ページの削除・回転

サムネールでページを選んでdeleteを押すと削除できます。横向きになってしまったページは、ページを選んでcommand + R（右回転）またはcommand + L（左回転）で直せます。

3. 画像をPDFにする

写真やスクショを複数選んでプレビューで開き、「ファイル」→「プリント」→左下の「PDF」→「PDFとして保存」を選ぶと、1つのPDFにまとめられます。手書きのノートを撮影して提出するときに便利です。

4. PDFに書き込む・署名する

ツールバーのペンのアイコン（マークアップツール）を押すと、テキストの追加、図形、ハイライト、手書きの署名などを書き込めます。配布されたPDFのプリントに直接回答を書き込みたいときに使えます。

5. PDFのファイルサイズを小さくする

  1. PDFをプレビューで開く
  2. 「ファイル」→「書き出す」を選ぶ
  3. 「Quartzフィルタ」で「Reduce File Size（ファイルサイズを減らす）」を選んで保存

画像が多いPDFは大きく小さくなりますが、画質がかなり落ちることもあります。保存後に中身を確認して、文字が読めるかチェックしましょう。元のファイルは上書きせず、別名で保存するのがおすすめです。

WordやPagesの書類をPDFにする

  • Word：「ファイル」→「名前を付けて保存」→ファイル形式で「PDF」を選ぶ
  • Pages：「ファイル」→「書き出す」→「PDF」
  • どのアプリでも：「プリント」→左下の「PDF」→「PDFとして保存」

提出前に、PDFにしたときにレイアウトが崩れていないか、必ず開いて確認しましょう。

まとめ

  • スクショはcommand + shift + 4、controlを足すとコピー
  • 保存先はcommand + shift + 5→「オプション」で変更
  • PDFの結合・並べ替え・回転・書き込み・圧縮はプレビューだけでできる

ほかにも作業が速くなる操作は、Macの便利なショートカットキーの記事で紹介しています。

※macOSのバージョンによって、メニューの名前や場所が少し異なる場合があります。
