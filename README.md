# キャンパスギア

大学生のPC・ガジェット・デザインのブログ　https://sei627appple.github.io/campus-gear/

## フォルダの中身

| ファイル・フォルダ | 役割 |
|---|---|
| `_src/` | 記事の元の文章（**記事を書く・直すときはここを編集**） |
| `_build.py` | `_src/` の記事からブログのページを自動で組み立てるプログラム |
| `posts/` | 組み立てられた記事ページ（自動で作られるので直接いじらない） |
| `index.html` / `about.html` / `sitemap.xml` | トップページなど（自動で作られる） |
| `style.css` | デザイン（色・文字の大きさなど） |
| `favicon.svg` | ロゴマーク |

`_` で始まるファイルやフォルダは、ブログには公開されません。

## 記事を直す・追加する手順

1. `_src/` の中の記事ファイルを編集する（新しい記事は、既存の記事ファイルをコピーして作る）
2. VS Code のターミナル（メニューの「ターミナル」→「新しいターミナル」）で次を実行する

   ```
   python3 _build.py
   ```

   目次・記事一覧・前後の記事・サイトマップが自動で作り直されます。
3. GitHub Desktop で「Commit to main」→「Push origin」

## 記事ファイルの書き方

1行目に記事の情報、2行目から本文（HTML）を書きます。

```
<!--META {"slug":"ファイル名（英数字）","title":"記事タイトル","description":"検索結果に出る説明","excerpt":"記事一覧に出る短い説明","date":"2026-10-01","cat":"カテゴリ","order":11} -->
  <p>本文……</p>

  <h2>見出し</h2>
  <p>本文……</p>
```

- `cat`（カテゴリ）：PC選び / Mac / PCトラブル / ガジェット / デザイン / 大学生活
- `order`：同じ日付の記事の並び順（大きいほど上）
- 見出し `<h2>` が3つ以上あると、自動で目次が付きます
